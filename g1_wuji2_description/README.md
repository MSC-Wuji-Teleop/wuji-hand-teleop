# g1_wuji2_description

Composed Unitree G1 (29 DoF) + dual Wuji Hand 2 (2x 20 DoF) model for
the gloves + PICO 4 -> simulation milestone. Self-contained: every
referenced mesh lives under `meshes/`.

| File | What |
|---|---|
| `g1_wuji2.xml` | MJCF, floating base. nq 76, nv 75, nu 69. |
| `g1_wuji2_fixed.xml` | MJCF, pelvis welded at the stand pose. nq = nv = nu = 69. Use this for upper-body sim control: on hardware the legs are owned by the G1's onboard balance controller. |
| `scene_g1_wuji2.xml` | Floor and lighting scene including `g1_wuji2.xml`, for the viewer. |
| `g1_wuji2.urdf` | URDF mirror, fixed base, 69 revolute joints. Joint limits cross-checked against the MJCF at 1e-4. |

Facts:

- Actuator and `ctrl` order: G1 29 (legs 12, waist 3, arms 14), then
  left hand 20, then right hand 20.
- All actuators are position servos. G1 joints: kp 500, critically
  damped per joint. Hand joints: vendor gains (kp 0.2 to 0.7, torque
  clamps 0.3 to 0.6 N m).
- Both MJCF files carry a `stand` keyframe.
- The wrist-to-hand transform is provisional. The physical G1-to-Hand2
  adapter is not designed yet; the hand mounts at the Unitree palm
  flange plane (x = 0.0415 m on `wrist_yaw_link`) with zero plate
  thickness. The model regenerates when the adapter CAD exists.
- Generated by `scripts/build_g1_wuji2.py` in the msc_research repo
  (source of truth). Do not hand-edit these files; regenerate.

Viewer check:

```bash
python -m mujoco.viewer --mjcf="$PWD/g1_wuji2_description/scene_g1_wuji2.xml"
```
