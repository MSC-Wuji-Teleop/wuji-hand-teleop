# g1_wuji2_description

Composed Unitree G1 23-DoF + dual Wuji Hand 2 model for the
gloves + PICO 4 -> simulation milestone. Self-contained: every
referenced mesh lives under `meshes/`.

The lab's robots are the **23-DoF G1 variant** (confirmed 2026-08-24):
waist yaw only, 5-DoF arms (shoulder x3, elbow, wrist roll), no wrist
pitch/yaw. The earlier 29-DoF files were removed to prevent variant
confusion; they remain in the msc_research repo as `g1_29_wuji2*`.

| File | What |
|---|---|
| `g1_23_wuji2.xml` | MJCF, floating base. nq 70, nv 69, nu 63. |
| `g1_23_wuji2_fixed.xml` | MJCF, pelvis welded at the stand pose. nq = nv = nu = 63. Use this for upper-body sim control: on hardware the legs are owned by the G1's onboard balance controller. |
| `scene_g1_23_wuji2.xml` | Floor and lighting scene including `g1_23_wuji2.xml`, for the viewer. |
| `g1_23_wuji2.urdf` | URDF mirror, fixed base, 63 revolute joints. Joint limits cross-checked against the MJCF at 1e-4. |

Facts:

- Actuator and `ctrl` order: G1 23 (legs 12, waist yaw, arms 5 + 5),
  then left hand 20, then right hand 20.
- All actuators are position servos. G1 joints: kp 500, critically
  damped per joint (kv from the menagerie 29-DoF model by joint name).
  Hand joints: vendor gains (kp 0.2 to 0.7, clamps 0.3 to 0.6 N m).
- Both MJCF files carry a `stand` keyframe.
- Unitree ships no hand-less 23-DoF wrist: the stock URDF fuses the
  wrist-roll module and rubber hand into one link. Here that link
  carries a derived bare-wrist inertial (0.18693 kg, rubber hand
  subtracted by parallel axis) and a cropped mesh
  (`meshes/g1_23/*_wrist_roll_bare.STL`). The Wuji hand mounts at the
  ICP-located palm flange: wrist_roll + [0.1220, +-0.003, 0].
- The wrist-to-hand transform is otherwise provisional: the physical
  G1-to-Hand2 adapter is not designed yet (zero plate thickness). The
  model regenerates when the adapter CAD exists.
- Generated by `scripts/build_g1_23_wuji2.py` in the msc_research repo
  (source of truth; derivation provenance in
  `scripts/derive_g1_23_wrist.py` there). Do not hand-edit; regenerate.

python -m mujoco.viewer --mjcf="$PWD/src/g1_wuji2_description/scene_g1_23_wuji2.xml"
